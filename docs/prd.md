# AICH 產品規劃（PRD）

> 版本 2.0 · 2026-10 · 狀態：MVP 已實作（見 [roadmap](roadmap.md)）

## 1. 問題與定位

開發者與企業同時使用多家 AI 服務時，必須分別申請帳號、維護金鑰、處理各家不同的 API 格式、限流規則與帳單；任一供應商宕機就會直接影響產品。

**AICH（AI Computing Hub）** 是一個 AI 算力轉接與模型路由平台：

| 價值 | 說明 |
| --- | --- |
| 統一入口 Unified Gateway | 相容 OpenAI Chat Completions 協定。用戶只改 Base URL 與 API Key，既有程式碼不改即可切換所有模型。 |
| 智能路由 Smart Routing | 依任務類型、預算、延遲與可用性，自動派送至最適切的模型與節點。 |
| 成本與備援最佳化 | 集中採購 Token、金鑰池併發管理；單一供應商故障時秒級切換備援模型。 |
| 一份帳單 | 所有模型的 Token 統一換算為平台點數（Credits）。 |

## 2. 目標客群

| 客群 | 痛點 | 主要使用方式 | 對應方案 |
| --- | --- | --- | --- |
| 一般 AI 愛好者 | 想試多家模型但不想訂多個服務 | Web 聊天介面 | Free / Starter |
| 獨立開發者、Vibe Coders | 需要穩定 API、想省錢、常切換模型 | API Key + SDK | Pro |
| 中小企業、AI 新創 | 高可用、成本控管、資料隱私、團隊管理 | API + 管理後台 + BYOK | Enterprise |

### 3.2 智能路由引擎

| 策略 | 運作邏輯 | 適用場景 |
| --- | --- | --- |
| 自動備援 Failover | 依優先序嘗試；5xx、逾時、429、連線失敗即切換下一條路由；串流在首字前可備援 | 企業級高可用 |
| 成本優先 Cost | 以預估 Token × 路由價格排序，選最便宜的健康節點 | 預算敏感、摘要分類 |
| 延遲優先 Latency | 以 EWMA 延遲（串流用 TTFT）排序，未量測節點先探索 | 即時對話、客服 |
| 意圖路由 Intent | 分類為 code / long_context / reasoning / vision / simple / general，優先派送到帶對應標籤的路由 | 多樣化開發需求 |

詳見 [routing.md](routing.md)。

## 4. 商業模式

採「訂閱月費 + 通用點數」雙軌。1 Credit = US$0.000001。

| 方案 | 月費 | 每月點數 | 權益 |
| --- | --- | --- | --- |
| Free | $0 | 200,000 | Web UI、基礎模型 |
| Starter | $9.99 | 1,000,000 | Web UI、基礎模型轉接、智能路由 |
| Pro | $29.99 | 3,500,000 | 全模型、API Key、高優先級路由（完整備援深度） |
| Enterprise | $199+ | 自訂 | 自訂金鑰池（BYOK）、專屬備援、SLA、零數據留存、團隊控管 |

- **模型等級**：`basic`（所有方案）與 `premium`（Pro 以上）。
- **扣點**：⌈(輸入 tokens × 輸入價 + 輸出 tokens × 輸出價) ÷ 1,000,000⌉，價格單位為「點 / 1M tokens」（數值 = USD/1M tokens × 10⁶）。
  - 例：旗艦模型輸入 $3/1M → 每 1,000 輸入 tokens 扣 3,000 點；平價模型 $0.075/1M → 75 點。
- **毛利來源**：路由售價（由營運在後台設定）高於上游進價；集中採購折扣；快取命中零成本。

詳見 [billing.md](billing.md)。

## 5. 安全、風控與合規

- 零數據留存（ZDR）：用戶可自行開啟；啟用後不記錄內容、不快取，絕不用於訓練。
- Guardrails：敏感詞與 Prompt Injection 偵測，off / flag / block 三種模式。
- 濫用防禦：每金鑰 RPM / TPM；10 分鐘內持續超限 300 次自動停用金鑰；登入嘗試限制。
- 金鑰加密：AES-256-GCM，主金鑰由環境變數注入（正式環境建議由 KMS / Vault 提供）。

詳見 [security.md](security.md)。

## 6. 成功指標（KPI）

| 指標 | 目標（上線 3 個月） |
| --- | --- |
| Gateway 額外延遲（P95，不含上游） | < 20 ms |
| 請求成功率（含備援後） | ≥ 99.9% |
| 備援觸發後成功率 | ≥ 99% |
| 快取命中率（temperature=0 流量） | ≥ 15% |
| 付費轉換率（Free → 付費） | ≥ 5% |
| 毛利率 | ≥ 25% |

## 7. 非目標（本階段）

- 自建/託管開源模型推論叢集（可透過 OpenAI 相容端點接入 vLLM 等，不在平台內管理 GPU）。
- 圖片生成、語音、Embeddings 端點（列於 roadmap）。
- 線上刷卡結帳（目前由業務/管理員調整方案，`AICH_SELF_SERVICE_PLANS` 可於展示環境開啟自助切換）。
